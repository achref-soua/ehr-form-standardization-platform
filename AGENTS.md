# Repository operating rules

- Keep all changes inside this repository.
- Never add real patient, employer, credentialed, or private hospital data.
- Do not copy private interview preparation or compensation context into public files.
- Use `uv` for Python and `pnpm` for TypeScript dependencies.
- Use Conventional Commits with `Achref Soua <achref.soua@outlook.com>` and no co-author trailers.
- Do not create, configure, or push a Git remote without explicit owner authorization.
- New behavior requires tests and synchronized documentation.
- Never claim HDS certification, production validation, or clinical validity.
- Ask before destructive cleanup; cleanup commands must preview explicit repository-local targets.
